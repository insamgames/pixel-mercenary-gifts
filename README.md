# 픽셀 용병단 우편함 발송 가이드

이 저장소의 `gifts.json`을 수정하면 게임 우편함으로 선물이 발송돼요.
게임은 아래 주소를 읽어요.

```
https://insamgames.github.io/pixel-mercenary-gifts/gifts.json
```

## 우편함 발송 설명

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| `id` | 필수 | 선물 고유 번호. 글자·숫자 자유, 길이 자유. **한 번 쓴 id는 다시 쓰지 않아요.** 예: `1124-01` |
| `to` | 필수 | 받는 사람. 유저 ID 1명, 여러 명은 `[ ]` 안에 쉼표로 구분, 전체는 `"ALL"` |
| `msg` | 선택 | 우편함에 보이는 제목. 예: `결제 오류 보상` |
| `from` | 선택 | 이 날부터 보여요. 형식 `YYYY-MM-DD` |
| `until` | 선택 | 이 날까지 받을 수 있어요 (그날 포함). 형식 `YYYY-MM-DD` |

- 유저 ID는 게임 **설정** 화면에 있어요. 하이픈(`-`)은 있어도 없어도 되고, 대소문자도 상관없어요.
- 이미 받은 선물은 같은 `id`로 다시 받을 수 없어요.

## 보상 항목

필요한 것만 골라서 한 선물에 여러 개 넣을 수 있어요.

| 키 | 보상 | 예 |
| --- | --- | --- |
| `gems` | 보석 | `"gems": 3500` |
| `htix` | 영웅 소환권 | `"htix": 10` |
| `etix` | 장비 소환권 | `"etix": 10` |
| `ptix` | 펫 소환권 | `"ptix": 5` |
| `soul` | 영혼석 | `"soul": 20` |
| `goldMin` | 골드 (그 유저의 현재 골드 수입 기준 N분어치) | `"goldMin": 60` |
| `noads` | 광고 제거 | `"noads": true` |
| `vip` | 평생 회원권 (×3 배속 + 매일 보석 받기) | `"vip": true` |

- `vip`만으로는 즉시 보석 3,300개가 들어가지 않아요. 구매와 똑같이 주려면 `"gems": 3300`을 같이 넣어요.
- 이미 광고 제거·회원권을 가진 유저에게는 그 부분만 건너뛰고 나머지를 지급해요.

## 예시 1. 단일 사용자

```json
{
  "gifts": [
    { "id": "1124-01", "to": "K7Q2M9XA", "gems": 3500, "msg": "결제 오류 보상" }
  ]
}
```

## 예시 2. 다중 사용자

```json
{
  "gifts": [
    { "id": "1124-02", "to": ["K7Q2M9XA", "AB3D9FGH", "ZX8Q4M2P"], "htix": 5, "etix": 5, "msg": "버그 제보 감사 선물", "until": "2026-12-31" }
  ]
}
```

## 예시 3. 전체 사용자

```json
{
  "gifts": [
    { "id": "launch-01", "to": "ALL", "gems": 300, "goldMin": 60, "msg": "출시 기념 선물", "from": "2026-12-01", "until": "2026-12-31" }
  ]
}
```

## 여러 선물을 동시에 올릴 때

선물 사이에 **쉼표**를 넣어요. 마지막 선물 뒤에는 쉼표를 넣지 않아요.

```json
{
  "gifts": [
    { "id": "1124-01", "to": "K7Q2M9XA", "gems": 3500, "msg": "결제 오류 보상" },
    { "id": "launch-01", "to": "ALL", "gems": 300, "msg": "출시 기념 선물", "until": "2026-12-31" }
  ]
}
```

## 수정 순서

1. 저장소에서 `gifts.json` → 연필(✏️) 아이콘
2. 선물 추가·수정
3. **Commit changes**
4. 위 주소를 브라우저로 열어서 내용이 보이는지 확인 (반영까지 최대 10분)

## 주의

- 쉼표·따옴표·괄호가 하나라도 틀리면 게임이 파일 전체를 읽지 못해 **모든 선물이 안 보여요.** 수정 후 꼭 주소를 열어 확인해요.
- 지난 선물은 지우지 않고 `until`로 기한만 두면 기록 관리가 쉬워요. 지워도 이미 받은 유저에게는 영향이 없어요.
- 이 저장소는 공개라 누구나 파일을 볼 수 있어요. 유저 ID 외의 개인정보는 넣지 않아요.
